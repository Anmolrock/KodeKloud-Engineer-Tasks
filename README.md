# 🚀 KodeKloud Tasks -- Solutions

This repository contains solutions for **KodeKloud Engineer practice
tasks**.\
It covers a wide range of topics including Linux, Git, Kubernetes,
Docker, Ansible, Database, and more.

------------------------------------------------------------------------

## 📌 Topics Covered

### 🔹 Linux Administration

-   Crontab access restrictions\
-   Runlevel configuration (GUI mode)\
-   Timezone synchronization\
-   SELinux management\
-   Firewall configuration\
-   Process/user limits\
-   User/group management\
-   Security (disable root SSH login)\
-   File/directory permissions

### 🔹 Git

-   Repository setup (bare repos, cloning)\
-   Branching, merging, rebasing, cherry-picking\
-   Remotes configuration\
-   Hooks (post-update for release tags)\
-   Stash operations\
-   Reset/revert commits

### 🔹 Kubernetes

-   Deployments and Pods\
-   Namespaces\
-   ReplicaSets & ReplicationControllers\
-   CronJobs & Jobs\
-   ConfigMaps & Volumes\
-   Resource limits (CPU/Memory)\
-   Rolling updates & rollbacks\
-   Service updates (NodePort, scaling, images)

### 🔹 Cron Jobs

-   Installing & configuring `cronie`\
-   Root scheduled jobs

### 🔹 Ansible

-   Installation (via pip3, version 4.7.0)

### 🔹 Database

-   MariaDB service troubleshooting

### 🔹 Docker

-   Running containers (e.g., `nginx:alpine`)

### 🔹 YUM / Package Management

-   Local YUM repository setup\
-   Installing `epel-release`
